Dawah App - Privacy Policy

Effective Date: August 6, 2026

This Privacy Policy outlines how Dawah App collects, uses, and safeguards user information when accessing our services and OAuth integrations with third-party social media platforms.

1. Information We Collect

  • Account Identifiers: Basic account IDs and user profile identifiers granted via official OAuth authorization flows (e.g., TikTok, YouTube, Meta, X, LinkedIn).
  • Publishing Data: Media metadata, upload progress logs, and publishing execution metrics required to ensure reliable scheduling.
  • Technical Data: Standard server logs, API request timestamps, and error diagnostic logs.

2. How We Use Information

We process collected data exclusively to deliver requested functions: formatting educational book pages, scheduling automated posts, refreshing OAuth tokens, and monitoring publishing status. Dawah App does not sell, lease, or share personal data with third parties.

3. Token Management & Security

Authentication tokens (such as access and refresh tokens) are encrypted and stored in protected environment configurations. Tokens are utilized strictly for authorized publishing API requests.

4. Data Retention & Revocation

Users may revoke Dawah App's access at any time through their respective social platform account security settings (e.g., TikTok Authorized Apps, Google Account Security, Meta Connected Apps). Upon revocation, access tokens are permanently purged from our servers.
