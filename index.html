Frequently Asked Questions

Clear answers regarding platform compliance, data security, and service usage.

What is Dawah App?

Dawah App is an automated web application that assists content creators in publishing educational Islamic literature, daily book pages, and spiritual reminders across social media platforms via official developer APIs.

How is user data protected?

Dawah App uses OAuth 2.0 to grant access tokens without accessing user account passwords. Access tokens are stored securely in environment configurations and used strictly for scheduled publishing operations.

Does Dawah App comply with platform developer policies?

Yes. All API integrations strictly comply with developer terms of service, including TikTok App Review Guidelines, YouTube API Services Terms of Service, and Meta Platform Terms.
